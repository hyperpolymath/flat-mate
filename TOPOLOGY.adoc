=== Update Protocol

This file is maintained by both humans and AI agents. When updating:

[arabic]
. *After changing a component’s real state*: Update its row in the
status table — describe what exists, never a completion percentage
. *After adding a component*: Add a new row in the status table
. *After architectural changes*: Update the ASCII diagram
. *Date*: Update the `+Last updated+` comment at the top of this file
. *Consistency*: Never contradict `+.machine_readable/6a2/STATE.a2ml+`
or `+docs/design/squad-audit-v1.adoc+`
