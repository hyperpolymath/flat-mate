## Key Commands
- `just doctor` — diagnose toolchain issues
- `just tour` — guided project tour
- `just help-me` — help and issue-reporting pointers
- `deno task check` — typecheck/lint the API and shared domain
- `deno task dev:api` / `deno task dev:web` — run the legacy v0 API/web apps
- `deno test packages/shared` — run the matching-engine unit tests
